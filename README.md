# 🎥 Auto-Video Generation System – 1880 Town

This project automates the creation of personalized tour videos for tourists in 1880 Town using live camera feeds, AI video generation, and email delivery. It integrates real-time video streaming, Stable Diffusion video AI, and invoice generation through Square.

---

## 🚀 Tech Stack

- **Backend:** Django (Python)
- **Frontend:** React.js
- **Database:** SQL
- **Video Processing:** FFMpeg, MoviePy
- **Camera Integration:** Reolink API
- **AI Integration:** Stable Diffusion (Header/Footer video generation)
- **Email Services:** SMTP, IMAP
- **Invoice System:** Square API
- **PDF Handling:** Langchain (Affirmation Card PDF Generation)

---

## 🎯 Key Features

### 📹 Video Stream Management (FFMpeg)
- **RTSP to HLS** conversion with ultrafast encoding.
- Real-time streaming with segment rotation (only last 4 segments retained).
- **WebM to MP4** conversion with metadata repositioning to resolve duration issues.

### 📧 Email Automation
- Sends video links and interacts with users via SMTP & IMAP.
- Email verification process included.

### 🧠 AI & Media Functions
- Header/Footer video clips created using Stable Diffusion Video API.
- Final video generated by **concatenating header, recorded stream, and footer** via MoviePy.
- Langchain-based affirmation card PDF generation.

### 📷 Camera Integration
- Real-time video capture using Reolink API.

### 🧾 Payments & Invoicing
- Integration with **Square API** to generate and track invoices for services.

## 🛠 Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/1880town-video-generator.git
cd 1880town-video-generator
````

### 2. Backend Setup (Django)

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### 3. Frontend Setup (React)

```bash
cd frontend
npm install
npm start
```

### 4. Configure Environment Variables

* SMTP/IMAP Credentials
* Square API Keys
* Reolink API Configs
* Stable Diffusion Video API

---

## 📌 Notes

* Ensure Reolink cameras are network-accessible.
* FFMpeg must be installed and added to PATH.
* PDF generation is triggered based on email content (animal interaction logic).
